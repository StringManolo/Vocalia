# Vocalia

**Tu Android, solo con la voz.** Asistente de voz offline, sin Google, sin manos, sin mirar la pantalla. Diseñado para conductores, personas ciegas, personas sin movilidad en las manos, y cualquiera que quiera controlar su teléfono sin tocarlo.

---

## 📥 Descargar

**Última versión estable:** [`v0.3.0-sherpa`](https://github.com/StringManolo/Vocalia/releases)

APK directo: [`debug-apk.zip`](https://github.com/StringManolo/Vocalia/releases/download/V0.0.0-debug/debug-apk.zip)

> ⚠️ La APK está firmada con clave de debug. Android mostrará un aviso al instalar. Es normal: la app es sideload, no viene de Play Store. Quizás necesites desactivar playprotect para permitir la instalación.

---

## 🎯 ¿Qué es Vocalia?

Un asistente de voz que se ejecuta **íntegramente en tu dispositivo**, sin enviar audio a la nube, sin depender de servicios de Google Play, y sin que tengas que tocar la pantalla ni mirarla.

Piensa en Siri o Google Assistant, pero:

- **100% offline** para las tareas esenciales (voz a texto, texto a voz, comandos).
- **Sin Google Play Services**. Funciona en Huawei y en cualquier Android sin GMS.
- **Código abierto** (GPLv3 para uso personal).
- **Extensible** por módulos: TTS, STT, comandos, cada pieza se puede cambiar.

### ¿Para quién es?

- 🚛 **Conductores** de camión, taxi, reparto, que quieren programar, gestionar negocios o consultar cosas mientras conducen sin distraerse.
- 👁️ **Personas ciegas o con baja visión** que necesitan un control por voz total de su Android.
- 🦾 **Personas sin movilidad en las manos** que no pueden tocar la pantalla.
- 🍳 **Usuarios normales** que quieren usar el móvil con las manos ocupadas (cocinando, en el taller, etc.).

---

## ✨ Funcionalidades actuales (v0.3.0)

### Wake word

Di **"asistente"** y el sistema te responde. No hay que pulsar ningún botón.

### Comandos por voz

```
"asistente, hola"
"asistente, cómo estás"
"asistente, qué hora es"
"asistente, qué día es"
"asistente, usa voz inteligente"
"asistente, usa voz por defecto"
"asistente, descansa"
```

También funciona **wake word + comando en un solo turno**:

```
"asistente, qué hora es"   ← detecta wake word + comando a la vez
```

### Doble motor de voz

| Motor | Calidad | Uso |
| :--- | :--- | :--- |
| **espeak-ng** | Robótica, ligera | Default. Rápido, bajo consumo, siempre disponible. |
| **Piper (Sherpa-onnx)** | Neuronal, natural | Se activa por voz. Suena como un asistente moderno. |

Cambio en caliente:

```
Tú: "asistente, usa voz inteligente"
Vocalia: "cargando voz inteligente" → (1-4 s) → "voz inteligente activada"

Tú: "asistente, usa voz por defecto"
Vocalia: "voz por defecto activada"
```

### STT offline

Vosk con modelo español (`vosk-model-small-es-0.42`). Reconoce comandos y wake word sin conexión.

### Resistencia

- Arranca al encender el teléfono (`BOOT_COMPLETED`).
- `ForegroundService` con notificación persistente.
- Watchdog que lo relanza si muere.
- Exención de optimización de batería (evita que EMUI lo mate).
- Logs internos en `/sdcard/Android/data/io.github.stringmanolo.vocalia.debug/files/INTERNAL_DEBUG_FILE`.

## 🔧 Instalación

### Requisitos

- Android 7.0 (API 24) o superior.
- ARM64 (arm64-v8a). Cubre el 99% de móviles desde 2016.
- 200 MB de almacenamiento (modelo STT + modelos TTS + APK).
- 500 MB de RAM disponible.

### Pasos

1. **Descarga la APK** desde la última [release](https://github.com/StringManolo/Vocalia/releases).
2. **Instálala** (acepta "instalar desde fuentes desconocidas").
3. **Abre Vocalia**:
   - Concede permiso de notificaciones (Android 13+).
   - Concede permiso de micrófono.
   - Acepta la exención de batería.
4. **Pulsa "Iniciar servicio"**.
5. **Espera 5 segundos** (carga Vosk y espeak-ng).
6. **Di "asistente"**. Debe oírse un pitido y estar atento al siguiente comando.

### En Huawei / EMUI (importante)

EMUI es muy agresivo matando apps en segundo plano. Para que Vocalia funcione de verdad:

1. **Ajustes → Batería → Inicio de apps → Vocalia**:
   - Desactiva "Administrar automáticamente".
   - Activa "Autoinicio", "Ejecución en segundo plano", "Ejecución al bloquear pantalla".
2. **Ajustes → Batería → Optimización de batería**:
   - Busca Vocalia, selecciona "No permitir" (no optimizar).

Sin esto, EMUI matará el servicio a los minutos. Con esto, es estable.

## 🧪 Cómo probarlo

Con el servicio iniciado, di en voz alta y clara:

```
"asistente"
   → pitido corto

"qué hora es"
   → "son las 14 y 30"

"asistente, qué día es"
   → "hoy es jueves 29 de octubre"

"asistente, usa voz inteligente"
   → "cargando voz inteligente" ... "voz inteligente activada" (voz Piper)

"asistente, qué hora es"
   → "son las 14 y 31" (con voz Piper, mucho más natural)

"asistente, usa voz por defecto"
   → "voz por defecto activada" (vuelve a espeak)

"asistente, descansa"
   → "descanso" (vuelve a modo wake word)
```

Si algo no responde:

1. Abre **"Ver logs"** en la app.
2. Copia el contenido del `INTERNAL_DEBUG_FILE`.
3. Abre un issue con ese log y qué esperabas que pasara.

# Roadmap de Vocalia

**Documento vivo.** Última actualización: Fase 1.2 completada (v0.3.0-sherpa).

Este documento describe la visión, las fases, las decisiones técnicas y los casos límite que guían el desarrollo de Vocalia. Se actualiza al cerrar cada fase.

---

## 🎯 Visión

Construir un asistente de voz **totalmente offline y sin dependencias de Google** que permita controlar un Android **sin tocar la pantalla y sin mirarla**, para que cualquier persona pueda:

- **Programar y gestionar negocios** mientras conduce largas horas (caso del autor).
- **Usar el móvil con normalidad** siendo ciega o con baja visión.
- **Usar el móvil sin manos** (discapacidad motriz, conducción, cocina, taller).
- **Extenderlo** sin miedo: cada componente (STT, TTS, comandos) es modular y reemplazable.

### Principios de diseño

1. **Offline primero.** Todo lo esencial funciona sin red. La red solo para actualizaciones, feedback y plugins opcionales.
2. **Sin Google Play Services.** Debe funcionar en Huawei, dispositivos sin GMS, y versiones antiguas de Android.
3. **Modular.** Cada motor (STT, TTS, comandos) es una pieza independiente que se puede sustituir.
4. **Robusto.** Si un componente falla, el resto sigue vivo. Watchdog, fallbacks, recuperación automática.
5. **Instalable por un tercero sin conocimientos técnicos.** El objetivo final es un APK que cualquiera pueda instalar en el móvil de una persona ciega en 5 minutos.
6. **Open source (GPLv3 para uso personal).** Uso comercial con licencia aparte negociada caso por caso.

## 📅 Fases

### ✅ Fase 0 — Andamiaje

**Estado:** completada.

- [x] Repositorio `Vocalia` con template `KotlinApkTemplate`.

---

### ✅ Fase 1.1 — TTS offline con espeak-ng

**Estado:** completada.

- [x] Integración de `espeak-ng` (vía wrapper `com.reecedunn.espeak`).
- [x] Compilación del `.so` y `espeakdata.zip` desde GitHub Actions.
- [x] Voz española femenina (`roa/es`).
- [x] `AudioTrack` en `MODE_STREAM` con PCM 16-bit.
- [x] Ajuste de velocidad (`Rate.setValue(wpm)`).
- [x] Reproducción tras `synthesize()` (no dentro del callback nativo).

**Notas técnicas críticas:**
- EMUI de Huawei **no conecta el `AudioTrack` al mezclador si se crea dentro del callback nativo** de `synthesize()`. Hay que acumular PCM y reproducir después.
- `CONTENT_TYPE_MUSIC` funciona donde `CONTENT_TYPE_SPEECH` falla en Huawei.
- `setPreferredDevice` rompe el `AudioTrack` en el P40 Lite. No usar.
- `bufSize = pcm.size` funciona mejor que `bufSize = minBuf * 4` en EMUI.

---

### ✅ Fase 1.2 — Wake word + comandos + TTS dual

**Estado:** completada (v0.3.0-sherpa).

- [x] STT con Vosk modelo `small-es-0.42` (50 MB).
- [x] Wake word "asistente" (descartada "vocalia": no está en el vocabulario del modelo).
- [x] Máquina de estados `IDLE → LISTENING → EXECUTING → IDLE`.
- [x] Wake + comando en un solo turno ("asistente, qué hora es").
- [x] Timeout de 5 s en LISTENING, safety timeout de 30–60 s en EXECUTING.
- [x] Pitido corto (100 ms) al entrar en LISTENING (feedback no verbal).
- [x] Comandos: hora, fecha, hola, cómo estás, descansa.
- [x] TTS dual: espeak-ng (default) + Sherpa/Piper (voz natural).
- [x] Cambio de motor en caliente por voz ("usa voz inteligente" / "usa voz por defecto").
- [x] Carga de Sherpa bajo demanda (no al arrancar) para ahorrar RAM.
- [x] Copia de `espeak-ng-data` a `filesDir` para Sherpa (espeak-ng nativo necesita rutas reales, no assets).
- [x] Logcat dump al arrancar para capturar crashes nativos.

**Notas técnicas críticas:**
- Sherpa-onnx **2.0.0+ eliminó espeak-ng**. Los modelos Piper necesitan el AAR **1.13.4** o anterior.
- Sherpa 1.13.4 hace `SIGSEGV` si `espeak-ng-data` no está en disco. La copia a `filesDir` es obligatoria.
- `pickFirsts` en `build.gradle` con `libonnxruntime.so` puede causar más problemas de los que resuelve.
- Vosk no trae `libonnxruntime.so`; no hay conflicto con Sherpa en el APK.

---

### 🚧 Fase 1.3 — Intents para abrir apps

**Estado:** siguiente a empezar.

Objetivo: abrir cualquier app instalada por voz.

- [ ] `AppLauncher` con lista curada de apps comunes (`org.telegram.messenger`, `com.whatsapp`, `com.android.chrome`, `com.google.android.youtube`, `com.android.camera`, `com.android.settings`, `com.android.dialer`, `com.android.contacts`, etc.).
- [ ] Búsqueda difusa por nombre visible (`PackageManager.queryIntentActivities`).
- [ ] `QUERY_ALL_PACKAGES` en el manifest.
- [ ] `Intent.launchIntentForPackage` con fallback a `Intent.CATEGORY_LAUNCHER`.
- [ ] Comandos: "abre Telegram", "abre el navegador", "abre la cámara", "abre ajustes", "abre contactos", "abre el reloj".
- [ ] Gramática de Vosk actualizada con las frases de cada app + variantes.
- [ ] Fallback: "no encuentro esa app" si no hay match.

**Notas:**
- No requiere `AccessibilityService`. `startActivity` es suficiente para abrir apps.
- El `AndroidManifest` necesita `QUERY_ALL_PACKAGES` (Android 11+) para listar las apps instaladas.
- Futuro: "cierra [app]" requiere `ActivityManager.killBackgroundProcesses` o AccessibilityService (ver Fase 2).

---

### 🚧 Fase 1.4 — Dictado libre con buffer navegable

**Estado:** planificada.

Objetivo: dictar texto libre y poder navegarlo, editarlo y usarlo.

- [ ] Modo dictado (`Recognizer` sin gramática).
- [ ] Buffer de texto acumulativo.
- [ ] Comandos de transporte:
  - "repite" / "lee todo" / "borra último" / "borra todo".
  - "busca [término]" → salta a la primera ocurrencia y lee desde ahí.
  - "atrás" / "adelante" → mueve el puntero de lectura.
  - "copia al portapapeles".
  - "fin dictado" → vuelve a wake word.

## 🔧 Decisiones técnicas

### Stack elegido

| Componente | Tecnología | Motivo |
| :--- | :--- | :--- |
| **STT** | Vosk + `small-es-0.42` | Ligero, offline, latencia baja, gramática cerrada. |
| **TTS default** | espeak-ng | ~30 MB RAM, siempre disponible, fallback garantizado. |
| **TTS neuronal** | Sherpa-onnx 1.13.4 + Piper `es_ES-miro-high` | Voz natural, offline, ~250 MB RAM. |
| **Audio** | `AudioTrack` nativo | Control total. `MODE_STREAM` + PCM 16-bit + `CONTENT_TYPE_MUSIC`. |
| **Compilación** | GitHub Actions | Sin PC. Edición desde Termux. |
| **Logs** | `InternalDebug` (disco) | logcat no accesible en producción. |
| **Estado** | Máquina de estados en `VocaliaCore` | Separación clara de responsabilidades. |

### Restricciones autoimpuestas

- **Sin Google Play Services**. Ni Firebase, ni `FusedLocationProvider`, ni `SafetyNet`.
- **Sin red para tareas esenciales**. La nube solo para updates, feedback, plugins.
- **Sin hardware adicional**. Micrófono del móvil, auriculares estándar.
- **Un solo APK**. No dependencias de otros APKs (Termux es opcional).
- **Sin root**. Todo lo que se pueda, sin privilegios.

### Anti-patrones descubiertos (no repetir)

- ❌ `setPreferredDevice` en `AudioTrack` → rompe el track en Huawei.
- ❌ Reproducir dentro del callback nativo de `synthesize()` → `SIGSEGV` o `head=0`.
- ❌ `CONTENT_TYPE_SPEECH` en Huawei → no suena, `head=0`.
- ❌ Sherpa 2.0.0+ con modelos Piper → no hay espeak-ng, `samples=0`.
- ❌ Sherpa 1.13.4 sin `espeak-ng-data` en `filesDir` → `SIGSEGV`.
- ❌ `START_STICKY` con crashes nativos → bucle infinito de crashes.
- ❌ `packagingOptions` en AGP 8+ → `packaging`.
- ❌ `excludes` de `libonnxruntime.so` → elimina todas las copias.
- ❌ `pickFirsts` sin verificar el orden → puede elegir la versión incorrecta.
- ❌ Gramática de wake word con palabras inventadas → Vosk no las reconoce.
- ❌ Recrear `SpeechService` en cada cambio de gramática → pierde audio.

## ⚠️ Casos límite y consideraciones

### Legales

- **Conducción:** la legalidad del uso de dispositivos manos libres varía por país. Vocalia **no se hace responsable** del uso que se le dé. El README y `LEGALITY.md` advierten de que el usuario debe consultar la normativa de su país.
- **Grabación de audio:** la app no envía audio a la nube. Todo se procesa offline. No hay grabaciones persistentes más allá del buffer temporal en RAM.
- **Datos personales:** el `INTERNAL_DEBUG_FILE` puede contener texto reconocido por Vosk. El usuario es responsable de borrarlo si lo comparte.

### Técnicos

- **Memoria:** Vosk small (~400 MB) + Sherpa (~250 MB) + espeak (~30 MB) + Android + app pueden acercarse a 1 GB. En un P40 Lite con 4 GB va, pero el sistema puede matar procesos en segundo plano bajo presión.
- **Batería:** Vosk con micrófono siempre activo consume. Se recomienda cargar el móvil mientras se conduce.
- **Micrófono + altavoz simultáneos:** funciona en el P40 Lite. Otros dispositivos pueden requerir `MODE_IN_COMMUNICATION` y `speakerphone`. Hay que testear por dispositivo.
- **Wake word en entornos ruidosos:** el modelo small puede fallar. Opciones: modelo Vosk large, o wake word de dos palabras ("oye asistente").
- **Idioma:** Vosk y Piper son monolingües por modelo. Cambiar de idioma requiere cargar otro modelo. Planificado para Fase 1.5+.
- **Modelo Vosk small vs large:** el small es rápido pero limitado. Para dictado serio, evaluar Whisper.cpp en batch o Sherpa ASR.

### De instalación

- **Firma de debug:** el APK no está firmado con clave de release. Android muestra aviso al instalar. Aceptable para sideload.
- **Huawei/EMUI:** requiere configuración manual de batería (documentado en README). Sin esto, el servicio muere en minutos.
- **Xiaomi/MIUI:** problema similar. Habrá que documentar los pasos por fabricante.

## 🤝 Cómo contribuir

### Reportar un bug

1. Abre un issue en GitHub.
2. Incluye:
   - Modelo de dispositivo y versión de Android.
   - Pasos para reproducir.
   - El `INTERNAL_DEBUG_FILE` (`/sdcard/Android/data/io.github.stringmanolo.vocalia.debug/files/INTERNAL_DEBUG_FILE`).
   - Si la app crashea, el logcat del arranque posterior (el `[LOGCAT-ANTERIOR]` del log).

### Añadir un comando

1. Edita `CommandParser.kt`:
   ```kotlin
   matches(text, "tu-comando") -> CommandResult.Response("respuesta")
   ```
2. Edita la gramática en `VoskEngine.kt`:
   ```kotlin
   "tu-comando", "variante1", "variante2",
   ```
3. Commit, push, espera al APK.
4. Prueba y abre PR.

### Añadir un motor TTS

1. Implementa la interfaz `TtsEngine`.
2. Regístralo en `TtsManager`.
3. Añade un comando de voz para activarlo.
4. Commit, push, PR.

### Traducir a otro idioma

1. Añade el modelo Vosk del idioma en `assets/`.
2. Añade el modelo Piper del idioma (si existe).
3. Traduce las gramáticas y los mensajes.
4. Añade comando "habla en [idioma]".

package com.reecedunn.espeak;

import android.content.Context;
import android.util.Log;
import java.io.File;

public final class CheckVoiceData {

    private static final String TAG = "CheckVoiceData";

    private CheckVoiceData() {}

    /** Devuelve filesDir/espeak-data. Su PARENT (filesDir) es lo que SpeechSynthesis.nativeCreate recibe. */
    public static File getDataPath(Context context) {
        File dir = new File(context.getFilesDir(), "espeak-data");
        if (!dir.exists()) dir.mkdirs();
        return dir;
    }

    /** Los datos reales van a filesDir/espeak-ng-data/. */
    public static boolean hasBaseResources(Context context) {
        File dataDir = new File(context.getFilesDir(), "espeak-ng-data");
        boolean phontab = new File(dataDir, "phontab").exists();
        boolean phondata = new File(dataDir, "phondata").exists();
        if (!phontab || !phondata) {
            Log.w(TAG, "Datos base incompletos en " + dataDir.getAbsolutePath()
                    + " (phontab=" + phontab + ", phondata=" + phondata + ")");
        }
        return phontab && phondata;
    }
}

package com.reecedunn.espeak;

import java.io.ByteArrayOutputStream;
import java.io.File;
import java.io.FileInputStream;
import java.io.FileOutputStream;
import java.io.IOException;
import java.io.InputStream;

public class FileUtils {
    public static String read(File file) throws IOException {
        return readByteArray(new FileInputStream(file), (int)file.length()).toString();
    }

    public static String read(InputStream stream) throws IOException {
        return readByteArray(stream, stream.available()).toString();
    }

    public static String read(InputStream stream, int length) throws IOException {
        return readByteArray(stream, length).toString();
    }

    public static byte[] readBinary(File file) throws IOException {
        return readByteArray(new FileInputStream(file), (int)file.length()).toByteArray();
    }

    public static byte[] readBinary(InputStream stream) throws IOException {
        return readByteArray(stream, stream.available()).toByteArray();
    }

    public static byte[] readBinary(InputStream stream, int length) throws IOException {
        return readByteArray(stream, length).toByteArray();
    }

    private static ByteArrayOutputStream readByteArray(InputStream stream, int length) throws IOException {
        ByteArrayOutputStream content = new ByteArrayOutputStream(length);
        int c = stream.read();
        while (c != -1)
        {
            content.write((byte)c);
            c = stream.read();
        }
        return content;
    }

    public static void write(File outputFile, String contents) throws IOException {
        write(outputFile, contents.getBytes());
    }

    public static void write(File outputFile, byte[] contents) throws IOException {
        FileOutputStream outputStream = new FileOutputStream(outputFile);
        try {
            outputStream.write(contents, 0, contents.length);
        } finally {
            outputStream.close();
        }
    }

    public static void rmdir(File directory) {
        if (!directory.exists() || !directory.isDirectory()) {
            return;
        }

        for (File child : directory.listFiles()) {
            if (child.isDirectory()) {
                rmdir(child);
            }

            child.delete();
        }
    }
}

    private Locale getLocaleFromLanguageName(String name) {
        if (mLocaleFixes.containsKey(name)) {
            return mLocaleFixes.get(name);
        }
        String[] parts = name.split("-");
        switch (parts.length) {
            case 1: // language
                return new Locale(parts[0]);
            case 2: // language-country
                return new Locale(parts[0], parts[1]);
            case 3: // language-country-variant
                return new Locale(parts[0], parts[1], parts[2]);
            case 4: // language-country-x-privateuse
                return new Locale(parts[0], parts[1], parts[3]);
            default:
                return null;
        }
    }

    public List<Voice> getAvailableVoices() {
        final List<Voice> voices = new LinkedList<Voice>();
        final String[] results = nativeGetAvailableVoices();
        mVoiceCount = results.length / 4;

        for (int i = 0; i < results.length; i += 4) {
            final String name = results[i];
            final String identifier = results[i + 1];
            final int gender = Integer.parseInt(results[i + 2]);
            final int age = Integer.parseInt(results[i + 3]);

            try {
                final Locale locale;
                if (identifier.equals("asia/fa-en-us")) {
                    throw new IllegalArgumentException("Voice '" + identifier + "' is a duplicate voice.");
                } else {
                    locale = getLocaleFromLanguageName(name);
                    if (locale == null) {
                        throw new IllegalArgumentException("Locale not supported.");
                    }
                }

                String language = locale.getISO3Language();
                if (language.equals("")) {
                    throw new IllegalArgumentException("Language '" + locale.getLanguage() + "' not supported.");
                }

                String country  = locale.getISO3Country();
                if (country.equals("") && !locale.getCountry().equals("")) {
                    throw new IllegalArgumentException("Country '" + locale.getCountry() + "' not supported.");
                }

                final Voice voice = new Voice(name, identifier, gender, age, locale);
                voices.add(voice);
            } catch (MissingResourceException e) {
                // Android 4.3 throws this exception if the 3-letter language
                // (e.g. nci) or country (e.g. 021) code is missing for a locale.
                // Earlier versions return an empty string (handled above).
                Log.d(TAG, "getAvailableResources: skipping " + name + " => " + e.getMessage());
            } catch (IllegalArgumentException e) {
                Log.d(TAG, "getAvailableResources: skipping " + name + " => " + e.getMessage());
            }
        }

        return voices;
    }

package com.reecedunn.espeak;

import java.util.Locale;
import java.util.MissingResourceException;

import android.speech.tts.TextToSpeech;

public class Voice {
    public final String name;
    public final String identifier;
    public final int gender;
    public final int age;
    public final Locale locale;

    public Voice(String name, String identifier, int gender, int age, Locale locale) {
        this.name = name;
        this.identifier = identifier;
        this.gender = gender;
        this.age = age;
        this.locale = locale;
    }

    /**
     * Attempts a partial match against a query locale.
     *
     * @param query The locale to match.
     * @return A text-to-speech availability code. One of:
     *         <ul>
     *         <li>{@link TextToSpeech#LANG_NOT_SUPPORTED}
     *         <li>{@link TextToSpeech#LANG_AVAILABLE}
     *         <li>{@link TextToSpeech#LANG_COUNTRY_AVAILABLE}
     *         <li>{@link TextToSpeech#LANG_COUNTRY_VAR_AVAILABLE}
     *         </ul>
     */
    public int match(Locale query) {
        if (!locale.getISO3Language().equals(query.getISO3Language())) {
            return TextToSpeech.LANG_NOT_SUPPORTED;
        }
        try {
            if (!locale.getISO3Country().equals(query.getISO3Country())) {
                return TextToSpeech.LANG_AVAILABLE;
            }
        } catch (MissingResourceException e) {
            return TextToSpeech.LANG_AVAILABLE;
        }
        if (!locale.getVariant().equals(query.getVariant())) {
            return TextToSpeech.LANG_COUNTRY_AVAILABLE;
        }
        return TextToSpeech.LANG_COUNTRY_VAR_AVAILABLE;
    }

    @Override
    public String toString() {
        String ret = locale.getISO3Language();
        if (locale.getISO3Country() != null && !locale.getISO3Country().isEmpty()) {
            ret += '-';
            ret += locale.getISO3Country();
        }
        if (locale.getVariant() != null && !locale.getVariant().isEmpty()) {
            ret += '-';
            ret += locale.getVariant();
        }
        return ret;
    }
}

package com.reecedunn.espeak;

import java.util.regex.Pattern;

public class VoiceVariant {
    private static final Pattern mVariantPattern = Pattern.compile("-");

    public static final String MALE = "male";
    public static final String FEMALE = "female";

    public final String variant;
    public final int gender;
    public final int age;

    protected VoiceVariant(String variant, int age) {
        if (variant.equals(MALE)) {
            this.variant = null;
            this.gender = SpeechSynthesis.GENDER_MALE;
        } else if (variant.equals(FEMALE)) {
            this.variant = null;
            this.gender = SpeechSynthesis.GENDER_FEMALE;
        } else {
            this.variant = variant;
            this.gender = SpeechSynthesis.GENDER_UNSPECIFIED;
        }
        this.age = age;
    }

    @Override
    public String toString() {
        final String ret;
        if (gender == SpeechSynthesis.GENDER_MALE) {
            ret = MALE;
        } else if (gender == SpeechSynthesis.GENDER_FEMALE) {
            ret = FEMALE;
        } else {
            ret = variant;
        }
        if (age == SpeechSynthesis.AGE_YOUNG) {
            return ret + "-young";
        } else if (age == SpeechSynthesis.AGE_OLD) {
            return ret + "-old";
        }
        return ret;
    }

    public boolean equals(Object o) {
        if (o instanceof VoiceVariant) {
            VoiceVariant other = (VoiceVariant)o;
            if (variant == null || other.variant == null) {
                return other.variant == null && variant == null && other.gender == gender && other.age == age;
            }
            return other.variant.equals(variant) && other.gender == gender && other.age == age;
        }
        return false;
    }

    public static VoiceVariant parseVoiceVariant(String value) {
        String[] parts = mVariantPattern.split(value);
        int age = SpeechSynthesis.AGE_ANY;
        switch (parts.length) {
        case 1: // variant
            break;
        case 2: // variant-age
            age = parts[1].equals("young") ? SpeechSynthesis.AGE_YOUNG : SpeechSynthesis.AGE_OLD;
            break;
        default:
            return null;
        }
        return new VoiceVariant(parts[0], age);
    }
}

import io.github.stringmanolo.vocalia.util.VocaliaLogger

import android.app.AlarmManager
import android.content.BroadcastReceiver
import android.content.Context
import android.content.Intent

class BootReceiver : BroadcastReceiver() {

    override fun onReceive(context: Context, intent: Intent) {
        val action = intent.action ?: return
        if (action != Intent.ACTION_BOOT_COMPLETED &&
            action != Intent.ACTION_LOCKED_BOOT_COMPLETED &&
            action != "android.intent.action.QUICKBOOT_POWERON") return

        VocaliaLogger.i("BootReceiver", "Boot event: $action")

        // En Android 12+ no se puede arrancar un FGS directamente desde BOOT_COMPLETED.
        // Programamos una alarma ~5 s después, y esa alarma (WatchdogReceiver) sí arranca el servicio.
        val alarmManager = context.getSystemService(Context.ALARM_SERVICE) as AlarmManager
        val triggerAt = System.currentTimeMillis() + 5_000L
        val pi = WatchdogReceiver.pendingIntent(context, WatchdogReceiver.ACTION_BOOT_START, 100)
        alarmManager.setAndAllowWhileIdle(AlarmManager.RTC_WAKEUP, triggerAt, pi)

        // Arrancamos también el ciclo del watchdog
        WatchdogReceiver.scheduleWatchdog(context)
    }
}

    fun findPackage(name: String): String? {
        val query = normalize(name)
        if (query.isBlank()) return null

        val curated = knownApps[query]
        if (curated != null) {
            for (pkg in curated) {
                try {
                    if (context.packageManager.getLaunchIntentForPackage(pkg) != null) return pkg
                } catch (_: Throwable) {}
            }
        }

        val apps = getInstalledApps()
        val normalizedApps = apps.map { normalize(transliterateCyrillic(it.first)) to it }
        val exact = normalizedApps.firstOrNull { it.first == query }?.second
        val startsWith = exact ?: normalizedApps.firstOrNull { it.first.startsWith(query) }?.second
        val wordMatch = startsWith ?: normalizedApps.firstOrNull { (label, _) ->
            label.split("\\s+".toRegex()).any { it == query }
        }?.second
        return wordMatch?.second
    }

    private fun loadInstalledApps(): List<Pair<String, String>> {
        val pm = context.packageManager
        val intent = Intent(Intent.ACTION_MAIN, null).apply { addCategory(Intent.CATEGORY_LAUNCHER) }
        return try {
            pm.queryIntentActivities(intent, 0).mapNotNull { ri: ResolveInfo ->
                val label = ri.loadLabel(pm)?.toString() ?: return@mapNotNull null
                val pkg = ri.activityInfo?.packageName ?: return@mapNotNull null
                label to pkg
            }
        } catch (t: Throwable) {
            InternalDebug.mark("AppLauncher: loadInstalledApps THREW ${t.javaClass.simpleName}: ${t.message}")
            emptyList()
        }
    }

    fun launch(appName: String): Result {
        val query = normalize(appName)
        InternalDebug.mark("AppLauncher: launch(\"$appName\") norm=\"$query\"")

        val curated = knownApps[query]
        if (curated != null) {
            for (pkg in curated) {
                if (launchPackage(pkg)) {
                    val label = getLabelForPackage(pkg) ?: appName
                    InternalDebug.mark("AppLauncher: launch OK -> $pkg ($label)")
                    return Result.Ok(label)
                }
            }
            InternalDebug.mark("AppLauncher: curado \"$query\" sin match instalado")
        }

        val pkg = findPackage(appName)
        if (pkg != null) {
            InternalDebug.mark("AppLauncher: match \"$query\" -> $pkg")
            if (launchPackage(pkg)) {
                val label = getLabelForPackage(pkg) ?: appName
                return Result.Ok(label)
            }
        }

        InternalDebug.mark("AppLauncher: NO encontrado \"$query\"")
        return Result.NotFound(appName)
    }

                or Intent.FLAG_ACTIVITY_SINGLE_TOP
        )

        InternalDebug.mark("AppLauncher: startActivity OK -> $pkg")

    } catch (t: Throwable) {

        if (pkg == null) {
            InternalDebug.mark("AppLauncher: closeApp NO encontrado \"$appName\"")
            return Result.NotFound(appName)
        }
        val am = context.getSystemService(Context.ACTIVITY_SERVICE) as ActivityManager
        val foreground = isInForeground(pkg)
        InternalDebug.mark("AppLauncher: closeApp(\"$appName\") pkg=$pkg foreground=$foreground")
        am.killBackgroundProcesses(pkg)
        InternalDebug.mark("AppLauncher: killBackgroundProcesses OK -> $pkg")
        val label = getLabelForPackage(pkg) ?: appName
        return Result.Ok(label)
    }

        @Suppress("DEPRECATION")
        val tasks = (context.getSystemService(Context.ACTIVITY_SERVICE) as ActivityManager)
            .getRunningTasks(1)
        tasks.isNotEmpty() && tasks[0].topActivity?.packageName == pkg
    } catch (_: Throwable) { false }

    private fun getLabelForPackage(pkg: String): String? = try {

        val appInfo = pm.getApplicationInfo(pkg, 0)
        transliterateCyrillic(pm.getApplicationLabel(appInfo).toString())
    } catch (_: Throwable) { null }

    private fun transliterateCyrillic(input: String): String {
        val sb = StringBuilder()
        for (ch in input) {
            sb.append(cyrillicToSpanish[ch] ?: ch.toString())
        }
        return sb.toString()
    }

    private fun normalize(s: String): String =
        Normalizer.normalize(s.lowercase().trim(), Normalizer.Form.NFD)
            .replace("\\p{Mn}+".toRegex(), "")

package io.github.stringmanolo.vocalia.core

import java.text.SimpleDateFormat
import java.util.Date
import java.util.Locale

sealed class CommandResult {
    object Sleep : CommandResult()
    object ListApps : CommandResult()
    object ListAppsVerbose : CommandResult()
    object EnterContinuous : CommandResult()
    object ExitContinuous : CommandResult()
    object PauseTts : CommandResult()
    object ResumeTts : CommandResult()
    object CloseForegroundApp : CommandResult()
    object Help : CommandResult()
    data class Response(val text: String) : CommandResult()
    data class SetVoiceMode(val intelligent: Boolean) : CommandResult()
    data class OpenApp(val appName: String) : CommandResult()
    data class CloseApp(val appName: String) : CommandResult()
}

class CommandParser(private val appLauncher: AppLauncher? = null) {

    private val esLocale = Locale("es", "ES")

    private val openPrefixes = listOf(
        "abre la app ", "abre el ", "abre la ", "abre ",
        "abrir la app ", "abrir el ", "abrir la ", "abrir "
    )

    private val closePrefixes = listOf(
        "cierra la app ", "cierra el ", "cierra la ", "cierra ",
        "cerrar la app ", "cerrar el ", "cerrar la ", "cerrar ",
        "mata la app ", "mata el ", "mata la ", "mata ",
        "matar la app ", "matar el ", "matar la ", "matar "
    )

    fun parse(raw: String): CommandResult {
        val text = raw.lowercase(esLocale).trim()
        return when {
            text.isBlank() -> CommandResult.Response("no te he entendido")

            matches(text, "ayuda", "qué puedes hacer", "que puedes hacer",
                "qué sabes hacer", "que sabes hacer", "dime todo lo que puedes hacer",
                "dime lo que puedes hacer", "guía", "guia", "comandos",
                "lista de comandos", "qué comandos tienes", "que comandos tienes") ->
                CommandResult.Help

            matches(text, "lístame las apps", "listame las apps", "lista de apps disponibles",
                "lista completa de apps", "qué apps disponibles", "que apps disponibles",
                "todas las apps", "todas las aplicaciones") ->
                CommandResult.ListAppsVerbose

            matches(text, "lista de apps", "lista apps", "qué apps tengo", "que apps tengo",
                "lista de aplicaciones") ->
                CommandResult.ListApps

            // EnterContinuous antes que ResumeTts y PauseTts
            matches(text, "sal de escucha continua", "desactiva escucha continua", "desactiva modo continuo") ->
                CommandResult.ExitContinuous
            matches(text, "escucha continua", "modo continuo", "escucha constante") ->
                CommandResult.EnterContinuous

            matches(text, "pausa el tts", "pausa el texto", "pausa la lectura", "pausa lectura", "pausa voz",
                "para el tts", "para el texto", "para la lectura",
                "pausa", "para", "parar", "pausar", "silencio", "callate", "callá", "stop",
                "detente", "basta", "alto", "quieto") ->
                CommandResult.PauseTts

            matches(text, "continua el tts", "continua el texto", "continua la lectura", "continua lectura",
                "continua voz", "reanuda el tts", "reanuda la lectura", "sigue leyendo",
                "continua", "continúa", "reanuda", "sigue") ->
                CommandResult.ResumeTts

            extractCloseAppName(text) != null -> CommandResult.CloseApp(extractCloseAppName(text)!!)

            matches(text, "cierra esta app", "cierra la app actual", "cierra esto",
                "cierra la app que esté abierta", "cierra lo que hay delante") ->
                CommandResult.CloseForegroundApp

            extractAppName(text) != null -> CommandResult.OpenApp(extractAppName(text)!!)
            appLauncher?.hasApp(text) == true -> CommandResult.OpenApp(text)

            matches(text, "descansa", "descanso", "descansar", "cansa", "duerme", "dormir") ->
                CommandResult.Sleep

            matches(text, "inteligente", "piper", "neuronal", "natural") ->
                CommandResult.SetVoiceMode(intelligent = true)
            matches(text, "por defecto", "espeak", "robotica", "robotizada") ->
                CommandResult.SetVoiceMode(intelligent = false)

            matches(text, "hora") -> CommandResult.Response(currentTime())
            matches(text, "fecha", "dia") -> CommandResult.Response(currentDate())
            matches(text, "hola") -> CommandResult.Response("hola")
            matches(text, "estas", "tal") -> CommandResult.Response("bien, gracias")

            else -> CommandResult.Response("no entiendo")
        }
    }

    private fun extractAppName(text: String): String? {
        for (p in openPrefixes) {
            if (text.startsWith(p)) {
                val raw = text.removePrefix(p).trim()
                val stripped = raw
                    .removeSuffix(" callate").removeSuffix(" calla")
                    .removeSuffix(" por favor").removeSuffix(" ahora").removeSuffix(" ya")
                    .trim()
                return if (stripped.isNotBlank()) stripped else null
            }
        }
        return null
    }

    private fun extractCloseAppName(text: String): String? {
        for (p in closePrefixes) {
            if (text.startsWith(p)) {
                val raw = text.removePrefix(p).trim()
                val stripped = raw
                    .removeSuffix(" callate").removeSuffix(" calla")
                    .removeSuffix(" por favor").removeSuffix(" ahora").removeSuffix(" ya")
                    .trim()
                return if (stripped.isNotBlank()) stripped else null
            }
        }
        return null
    }

    private fun matches(text: String, vararg keywords: String): Boolean {
        val words = text.split("\\s+".toRegex()).filter { it.isNotBlank() }
        return keywords.any { kw ->
            if (kw.contains(" ")) text.contains(kw)
            else words.any { w -> w == kw || (w.startsWith(kw) && w.length - kw.length <= 3) }
        }
    }

    private fun currentTime(): String {
        val fmt = SimpleDateFormat("H 'y' mm", esLocale)
        return "son las ${fmt.format(Date())}"
    }

    private fun currentDate(): String {
        val fmt = SimpleDateFormat("EEEE d 'de' MMMM", esLocale)
        return "hoy es ${fmt.format(Date())}"
    }
}

    private var timeoutRunnable: Runnable? = null
    private var safetyRunnable: Runnable? = null
    private var resumeRunnable: Runnable? = null

    private val resumeDelayMs = 10L
    private val listeningTimeoutMs = 5_000L
    private val safetyTimeoutMs = 600_000L

    private val allPauseWords = setOf(
        "para", "pausa", "parar", "pausar", "stop",
        "silencio", "callate", "callá", "detente", "basta", "alto", "quieto"

    private fun enterIdle(speak: String? = null) {

        state = State.IDLE
        cancelTimeouts()
        voskEngine.stopListening()

        if (speak != null) {
            ttsManager.speak(speak,
                onStart = { enterTtsSpeaking() },
                onComplete = { if (state == State.IDLE) resumeListeningWithDelay() })

        if (speak != null) {

            resumeListeningWithDelay()

    private fun enterListening() {
        log("enterListening")
        state = State.LISTENING
        cancelTimeouts()
        voskEngine.beep()
        timeoutRunnable = Runnable {
            if (state == State.LISTENING) {
                log("timeout LISTENING")
                enterExecuting(State.IDLE)
                speakAndReturn("tiempo agotado") { enterIdle() }
            }
        }.also { mainHandler.postDelayed(it, listeningTimeoutMs) }
    }

    private fun enterExecuting(returnTo: State) {
        log("enterExecuting returnTo=$returnTo")
        returnStateAfterExecution = returnTo
        state = State.EXECUTING
        cancelTimeouts()
        voskEngine.stopListening()
        log("Vosk pausado durante EXECUTING")
        safetyRunnable = Runnable {
            if (state == State.EXECUTING) {
                log("safety timeout EXECUTING")
                afterExecution()
            }
        }.also { mainHandler.postDelayed(it, safetyTimeoutMs) }
    }

    private fun afterExecution() {
        when (returnStateAfterExecution) {
            State.CONTINUOUS -> enterContinuous()
            State.TTS_PAUSED -> enterTtsPaused()
            else -> enterIdle()
        }
    }

    private fun enterTtsSpeaking() {
        if (state == State.TTS_SPEAKING) return
        log("enterTtsSpeaking")
        state = State.TTS_SPEAKING
        cancelTimeouts()
        voskEngine.stopListening()
        voskEngine.setGrammar(GRAMMAR_TTS_SPEAKING)
        voskEngine.startListening()
        log("Vosk escuchando (TTS_SPEAKING)")
    }

    private fun enterTtsPaused() {
        log("enterTtsPaused")
        state = State.TTS_PAUSED
        cancelTimeouts()
        voskEngine.stopListening()
        voskEngine.setGrammar(fullGrammar)
        voskEngine.startListening()
        log("Vosk escuchando (TTS_PAUSED, gramática completa)")
    }

    private fun resumeListeningWithDelay() {
        resumeRunnable = Runnable {
            if (state != State.EXECUTING && state != State.TTS_SPEAKING && state != State.TTS_PAUSED) {
                voskEngine.startListening()
                log("Vosk reanudado tras ${resumeDelayMs}ms (state=$state)")
            }
        }.also { mainHandler.postDelayed(it, resumeDelayMs) }
    }

    private fun speakAndReturn(text: String, after: () -> Unit) {
        ttsManager.speak(text,
            onStart = { enterTtsSpeaking() },
            onComplete = {
                if (state == State.TTS_SPEAKING) {
                    state = State.EXECUTING
                    after()
                }
            })
    }

    private fun handleResult(json: String) {
        val text = extractText(json)
        if (text.isBlank() || text == "[unk]") return
        log("result: \"$text\" (state=$state)")

        when (state) {
            State.IDLE -> {
                val (hasWake, remainder) = extractWake(text)
                if (hasWake) {
                    enterListening()
                    if (remainder.isNotBlank()) handleCommand(remainder, State.IDLE)
                }
            }
            State.LISTENING -> {
                val (hasWake, remainder) = extractWake(text)
                if (hasWake && remainder.isNotBlank()) {
                    cancelTimeouts(); voskEngine.beep(); handleCommand(remainder, State.IDLE)
                } else if (hasWake) {
                    cancelTimeouts(); voskEngine.beep(); enterListening()
                } else {
                    handleCommand(text, State.IDLE)
                }
            }
            State.CONTINUOUS -> {
                val (hasWake, remainder) = extractWake(text)
                val command = if (hasWake && remainder.isNotBlank()) remainder else text
                handleCommand(command, State.CONTINUOUS)
            }
            State.TTS_SPEAKING -> {
                val (hasWake, _) = extractWake(text)
                val textLower = text.lowercase()
                val words = textLower.split("\\s+".toRegex()).filter { it.isNotBlank() }
                val userPauseWord = words.firstOrNull { it in allPauseWords }

                when {
                    userPauseWord == null ->
                        log("TTS_SPEAKING: no pause word, ignorando")
                    hasWake -> {
                        log("TTS_SPEAKING: pausa por '$userPauseWord' (con wake word)")
                        ttsManager.pause()
                        enterTtsPaused()
                    }
                    else -> {
                        // Sin wake word: rechazar para evitar eco del propio TTS
                        log("TTS_SPEAKING: '$userPauseWord' sin wake word, ignorando (anti-eco)")
                    }
                }
            }
            State.TTS_PAUSED -> {
                val (hasWake, remainder) = extractWake(text)
                val command = when {
                    hasWake && remainder.isNotBlank() -> remainder
                    hasWake -> ""
                    else -> text
                }
                if (command.isBlank()) return
                val parsed = commandParser.parse(command)
                when (parsed) {
                    is CommandResult.ResumeTts -> {
                        log("TTS_PAUSED: reanudar")
                        ttsManager.resume()
                        enterTtsSpeaking()
                    }
                    CommandResult.Sleep, is CommandResult.ExitContinuous -> {
                        log("TTS_PAUSED: cancelar")
                        ttsManager.stop()
                        speakAndReturn("descanso") { enterIdle() }
                    }
                    else -> {
                        log("TTS_PAUSED: comando nuevo, se abandona la lectura pausada")
                        ttsManager.stop()
                        handleCommand(command, State.IDLE)
                    }
                }
            }
            State.EXECUTING -> log("ignorando result (EXECUTING)")
        }
    }

    private fun handleCommand(text: String, returnTo: State) {
        log("handleCommand: \"$text\" returnTo=$returnTo")
        if (ttsManager.isSpeaking()) {
            log("handleCommand: cancelando TTS en curso")
            ttsManager.stop()
        }
        val parsed = commandParser.parse(text)
        val forceIdle = parsed is CommandResult.Sleep || parsed is CommandResult.ExitContinuous
        enterExecuting(if (forceIdle) State.IDLE else returnTo)

        when (parsed) {
            CommandResult.Sleep -> speakAndReturn("descanso") { enterIdle() }
            CommandResult.ExitContinuous -> speakAndReturn("escucha continua desactivada") { enterIdle() }
            CommandResult.EnterContinuous -> speakAndReturn("escucha continua activada") { enterContinuous() }
            CommandResult.PauseTts -> { log("PauseTts fuera de TTS_SPEAKING, ignorado"); afterExecution() }
            CommandResult.ResumeTts -> { log("ResumeTts fuera de TTS_PAUSED, ignorado"); afterExecution() }
            CommandResult.Help -> {
                log("Help solicitado")
                speakAndReturn(HELP_TEXT) { afterExecution() }
            }
            CommandResult.ListApps -> {
                val all = appLauncher.getAllAppsForTTS()
                log("ListApps: ${all.size} apps")
                val msg = if (all.isEmpty()) "no tengo apps instaladas"
                else "tengo ${all.size} apps instaladas. Son: ${all.joinToString(", ")}"
                speakAndReturn(msg) { afterExecution() }
            }
            CommandResult.ListAppsVerbose -> {
                val all = appLauncher.getAllAppsForTTS()
                log("ListAppsVerbose: ${all.size} apps")
                all.forEach { app ->
                    val aliases = appLauncher.getAliasesForApp(app)
                    if (aliases.isEmpty()) log("ListAppsVerbose:   - $app")
                    else log("ListAppsVerbose:   - $app (di: ${aliases.joinToString(" / ")})")
                }
                val msg = if (all.isEmpty()) "no tengo apps instaladas"
                else "tengo ${all.size} apps instaladas. Son: ${all.joinToString(", ")}"
                speakAndReturn(msg) { afterExecution() }
            }
            is CommandResult.Response -> speakAndReturn(parsed.text) { afterExecution() }
            is CommandResult.SetVoiceMode -> {
                if (parsed.intelligent) {
                    ttsManager.speak("cargando voz inteligente",
                        onStart = { enterTtsSpeaking() },
                        onComplete = {
                            ttsManager.setEngineAsync(TtsManager.EngineMode.SHERPA) { ok, msg ->
                                mainHandler.post {
                                    log("setEngine(SHERPA): ok=$ok, msg=$msg")
                                    speakAndReturn(msg) { afterExecution() }
                                }
                            }
                        })
                } else {
                    ttsManager.setEngineAsync(TtsManager.EngineMode.ESPEAK) { ok, msg ->
                        mainHandler.post {
                            log("setEngine(ESPEAK): ok=$ok, msg=$msg")
                            speakAndReturn(msg) { afterExecution() }
                        }
                    }
                }
            }
            is CommandResult.OpenApp -> {
                val r = appLauncher.launch(parsed.appName)
                val message = when (r) {
                    is AppLauncher.Result.Ok -> "abriendo ${r.appName}"
                    is AppLauncher.Result.NotFound -> "no encuentro la app ${parsed.appName}"
                    is AppLauncher.Result.Error -> "no pude abrir ${parsed.appName}"
                }
                log("OpenApp(\"${parsed.appName}\") -> $message")
                speakAndReturn(message) { afterExecution() }
            }
            is CommandResult.CloseApp -> {
                val pkg = appLauncher.findPackage(parsed.appName)
                if (pkg == null) {
                    speakAndReturn("no encuentro la app ${parsed.appName}") { afterExecution() }
                } else {
                    log("CloseApp(\"${parsed.appName}\") pkg=$pkg")
                    appLauncher.bringVocaliaToFront()
                    mainHandler.postDelayed({
                        val r = appLauncher.closeApp(parsed.appName)
                        val message = when (r) {
                            is AppLauncher.Result.Ok -> "cerrando ${r.appName}"
                            is AppLauncher.Result.NotFound -> "no encuentro la app ${parsed.appName}"
                            is AppLauncher.Result.Error -> "no pude cerrar ${parsed.appName}"
                        }
                        log("CloseApp(\"${parsed.appName}\") -> $message")
                        speakAndReturn(message) { afterExecution() }
                    }, 600)
                }
            }
            CommandResult.CloseForegroundApp -> {
                log("CloseForegroundApp: trayendo Vocalia al frente")
                appLauncher.bringVocaliaToFront()
                speakAndReturn("cerrando app actual") { afterExecution() }
            }
        }
    }

    /** Matches wake word only at START of text. Returns (hasWake, remainder). */
    private fun extractWake(text: String): Pair<Boolean, String> {
        val lower = text.lowercase().trim()
        for (w in WAKE_WORDS) {
            if (lower.startsWith(w)) {
                val remainder = lower.substring(w.length).trim()
                return true to remainder
            }
        }
        return false to ""
    }

    private fun extractText(json: String): String = try {
        JSONObject(json).optString("text", "").trim()
    } catch (_: Exception) { "" }

    private fun cancelTimeouts() {
        timeoutRunnable?.let { mainHandler.removeCallbacks(it) }; timeoutRunnable = null
        safetyRunnable?.let { mainHandler.removeCallbacks(it) }; safetyRunnable = null
        resumeRunnable?.let { mainHandler.removeCallbacks(it) }; resumeRunnable = null
    }
}

class EspeakNgEngine(context: Context) : TtsEngine {

    override val name = "EspeakNg"
    override var onComplete: (() -> Unit)? = null
    @Volatile private var paused = false

    companion object {
        private const val TAG = "EspeakNgEngine"

        private const val TTS_VARIANT = "female"
        private const val WRITE_CHUNK = 4096

        private val initLock = Any()

        @Volatile private var activeEngine: EspeakNgEngine? = null

            Thread(r, "espeak-synth").apply { isDaemon = true }
        }
    }

    private val ctx: Context = context.applicationContext
    private val mainHandler = Handler(Looper.getMainLooper())
    private val audioManager: AudioManager by lazy {
        ctx.getSystemService(Context.AUDIO_SERVICE) as AudioManager
    }

    @Volatile private var initialized = false
    @Volatile private var shuttingDown = false
    @Volatile private var pendingText: String? = null

    private val generation = AtomicInteger(0)
    @Volatile private var synthGeneration = 0
    private var focusRequest: AudioFocusRequest? = null
    @Volatile private var pcmBuffer: ByteArrayOutputStream? = null
    @Volatile private var currentTrack: AudioTrack? = null

    override fun init(onReady: () -> Unit, onError: (String) -> Unit) {
        Thread({ initWorker(onReady, onError) }, "espeak-init").start()
    }

    private fun initWorker(onReady: () -> Unit, onError: (String) -> Unit) {
        try {
            extractVoiceDataIfNeeded()
            val s = obtainSharedSynth()

            if (s.sampleRate <= 0) {
                mainHandler.post { onError("SpeechSynthesis no se inicializó (sampleRate=0)") }
                return
            }

            selectVoice(s, TTS_LANGUAGE, TTS_VARIANT)
            try { s.Rate.setValue(175) } catch (_: Throwable) {}

            activeEngine = this
            initialized = true

            mainHandler.post { onReady() }

            pendingText?.let { text ->
                pendingText = null
                speak(text)
            }
        } catch (t: Throwable) {
            Log.e(TAG, "Error init: ${t.message}", t)
            mainHandler.post { onError(t.message ?: "Error desconocido") }
        }
    }

    private fun selectVoice(s: SpeechSynthesis, language: String, variant: String) {
        try {
            val voices = s.availableVoices
            val target: Voice? = voices.firstOrNull { it.identifier == languageIdentifierFor(language) }
                ?: voices.firstOrNull { it.locale?.language == language }
            if (target != null) {
                VoiceVariant.parseVoiceVariant(variant)?.let { v ->
                    s.setVoice(target, v)
                }
            }
        } catch (t: Throwable) {
            Log.w(TAG, "selectVoice falló: ${t.message}")
        }
    }

    private fun languageIdentifierFor(lang: String): String = when (lang) {
        "es" -> "roa/es"
        "ca" -> "roa/ca"
        "en" -> "gmw/en"
        else -> lang
    }

    private fun obtainSharedSynth(): SpeechSynthesis {
        return synchronized(initLock) {
            sharedSynth ?: run {
                val callback = object : SpeechSynthesis.SynthReadyCallback {
                    override fun onSynthDataReady(audioData: ByteArray) {
                        activeEngine?.onPcm(audioData)
                    }
                    override fun onSynthDataComplete() {}
                    override fun onSynthWordBoundary(textPosition: Int, textLength: Int, markerInFrames: Int) {}
                }
                val created = SpeechSynthesis(ctx, callback)
                sharedSynth = created
                created
            }
        }
    }

    private fun extractVoiceDataIfNeeded() {
        if (safeHasBaseResources()) return

        val filesRoot = ctx.filesDir
        val dataDir = File(filesRoot, "espeak-ng-data")
        File(filesRoot, "espeak-data").listFiles()?.forEach { it.deleteRecursively() }
        if (dataDir.exists()) dataDir.deleteRecursively()

        val resId = ctx.resources.getIdentifier("espeakdata", "raw", ctx.packageName)
        if (resId == 0) throw IllegalStateException("res/raw/espeakdata.zip no encontrado")

        val tempZip = File(ctx.cacheDir, "espeakdata.zip")
        ctx.resources.openRawResource(resId).use { input ->
            tempZip.outputStream().use { input.copyTo(it) }
        }

        ZipInputStream(tempZip.inputStream().buffered()).use { zis ->
            var entry = zis.nextEntry
            while (entry != null) {
                val target = File(filesRoot, entry.name)
                if (target.canonicalPath.startsWith(filesRoot.canonicalPath + File.separator) ||
                    target.canonicalPath == filesRoot.canonicalPath
                ) {
                    if (entry.isDirectory) target.mkdirs()
                    else {
                        target.parentFile?.mkdirs()
                        target.outputStream().use { zis.copyTo(it) }
                    }
                }
                zis.closeEntry()
                entry = zis.nextEntry
            }
        }
        tempZip.delete()
    }

    private fun safeHasBaseResources(): Boolean = try {
        CheckVoiceData.hasBaseResources(ctx)
    } catch (_: Throwable) { false }

    private fun requestAudioFocus() {
        if (focusRequest != null) return
        try {
            val attrs = AudioAttributes.Builder()
                .setUsage(AudioAttributes.USAGE_MEDIA)
                .setContentType(AudioAttributes.CONTENT_TYPE_MUSIC)
                .build()
            val req = AudioFocusRequest.Builder(AudioManager.AUDIOFOCUS_GAIN_TRANSIENT_MAY_DUCK)
                .setAudioAttributes(attrs)
                .build()
            audioManager.requestAudioFocus(req)
            focusRequest = req
        } catch (_: Throwable) {}
    }

    private fun abandonAudioFocus() {
        focusRequest?.let {
            try { audioManager.abandonAudioFocusRequest(it) } catch (_: Throwable) {}
            focusRequest = null
        }
    }

    private fun onPcm(pcm: ByteArray) {
        if (shuttingDown) return
        if (synthGeneration != generation.get()) return
        pcmBuffer?.write(pcm)
    }

    private fun playCleanly(pcm: ByteArray, gen: Int) {
        var t: AudioTrack? = null
        try {
            requestAudioFocus()
            val rate = sharedSynth?.sampleRate ?: 22050
            val minBuf = AudioTrack.getMinBufferSize(rate, AudioFormat.CHANNEL_OUT_MONO, AudioFormat.ENCODING_PCM_16BIT)
            val bufSize = maxOf(minBuf, pcm.size)

            t = AudioTrack.Builder()
                .setAudioAttributes(
                    AudioAttributes.Builder()
                        .setUsage(AudioAttributes.USAGE_MEDIA)
                        .setContentType(AudioAttributes.CONTENT_TYPE_MUSIC)
                        .build()
                )
                .setAudioFormat(
                    AudioFormat.Builder()
                        .setEncoding(AudioFormat.ENCODING_PCM_16BIT)
                        .setSampleRate(rate)
                        .setChannelMask(AudioFormat.CHANNEL_OUT_MONO)
                        .build()
                )
                .setBufferSizeInBytes(bufSize)
                .setTransferMode(AudioTrack.MODE_STREAM)
                .build()

            if (t.state != AudioTrack.STATE_INITIALIZED) return
            currentTrack = t
            t.play()

            var offset = 0
            while (offset < pcm.size) {
                if (gen != generation.get()) break
                if (paused) {
                    try { t.pause() } catch (_: Throwable) {}
                    while (paused && gen == generation.get()) Thread.sleep(50)
                    if (gen != generation.get()) break
                    try { t.play() } catch (_: Throwable) {}
                }
                val toWrite = minOf(WRITE_CHUNK, pcm.size - offset)
                val written = t.write(pcm, offset, toWrite)
                if (written <= 0) break
                offset += written
            }

            val frames = pcm.size / 2
            val expectedMs = frames * 1000L / rate
            val deadline = SystemClock.elapsedRealtime() + expectedMs + 2000L
            while (SystemClock.elapsedRealtime() < deadline) {
                if (gen != generation.get()) break
                if (t.playbackHeadPosition >= frames) break
                Thread.sleep(40)
            }
            Thread.sleep(100)
        } catch (ex: Throwable) {
            Log.e(TAG, "playCleanly: ${ex.message}", ex)
        } finally {
            try { t?.stop() } catch (_: Throwable) {}
            try { t?.release() } catch (_: Throwable) {}
            if (currentTrack === t) currentTrack = null
            abandonAudioFocus()
        }
        val cb = onComplete
        onComplete = null
        cb?.invoke()
    }

    override fun speak(text: String, interruptible: Boolean) {
        if (!initialized) { pendingText = text; return }
        val s = sharedSynth ?: return

        val gen: Int
        if (interruptible) {
            gen = generation.incrementAndGet()
            try { s.stop() } catch (_: Throwable) {}
            abandonAudioFocus()
        } else {
            gen = generation.get()
        }

        synthExecutor.execute {
            if (shuttingDown || generation.get() != gen) return@execute
            try {
                synthGeneration = gen
                val pcmOut = ByteArrayOutputStream()
                pcmBuffer = pcmOut

                s.synthesize(text, false)

                pcmBuffer = null
                val pcmBytes = pcmOut.toByteArray()
                if (pcmBytes.isNotEmpty() && generation.get() == gen) {
                    playCleanly(pcmBytes, gen)
                } else {
                    val cb = onComplete
                    onComplete = null
                    cb?.invoke()
                }
            } catch (t: Throwable) {
                Log.e(TAG, "speak: ${t.message}", t)
                pcmBuffer = null
                val cb = onComplete
                onComplete = null
                cb?.invoke()
            }
        }
    }

    override fun stop() {
        generation.incrementAndGet()
        try { sharedSynth?.stop() } catch (_: Throwable) {}
        abandonAudioFocus()
        paused = false
        val cb = onComplete
        onComplete = null
        cb?.invoke()
    }

    override fun pause() { paused = true }
    override fun resume() { paused = false }
    override fun isPaused(): Boolean = paused

    override fun setSpeed(rate: Float) {
        try {
            sharedSynth?.Rate?.setValue((175 * rate).toInt().coerceIn(80, 450))
        } catch (_: Throwable) {}
    }

    override fun shutdown() {
        shuttingDown = true
        stop()
        if (activeEngine === this) activeEngine = null
        initialized = false
    }
}

class SherpaOnnxEngine(private val context: Context) : TtsEngine {

    companion object {
        private const val ASSET_DIR = "tts/vits-piper-es_ES-miro-high"
        private const val ONNX_FILE = "es_ES-miro-high.onnx"
        private const val TOKENS_FILE = "tokens.txt"

    override val name = "SherpaOnnx"
    @Volatile override var onComplete: (() -> Unit)? = null
    @Volatile private var paused = false

    private var tts: OfflineTts? = null
    private val scope = CoroutineScope(Dispatchers.Default + SupervisorJob())
    private var currentJob: Job? = null

    @Volatile private var currentTrack: AudioTrack? = null
    @Volatile private var shuttingDown = false
    @Volatile private var currentSpeed = 1.0f

    private fun dbg(msg: String) {
        InternalDebug.mark("[${Thread.currentThread().name}] Sherpa: $msg")
    }

    override fun init(onReady: () -> Unit, onError: (String) -> Unit) {
        Thread({ initWorker(onReady, onError) }, "sherpa-init").start()
    }

    private fun initWorker(onReady: () -> Unit, onError: (String) -> Unit) {
        try {
            dbg("init.worker START")

            val base = ensureModelOnDisk()
            val basePath = base.absolutePath
            val dataDir = File(base, ESPEAK_DATA)
            dbg("init: base=$basePath")
            dbg("init: dataDir=$dataDir (phontab=${File(dataDir, "phontab").exists()}, phondata=${File(dataDir, "phondata").exists()})")

            if (!File(dataDir, "phontab").exists() || !File(dataDir, "phondata").exists()) {
                dbg("init: espeak-ng-data incompleto")
                onError("datos de voz incompletos en $dataDir")
                return
            }

            dbg("init: construyendo OfflineTts")
            val config = OfflineTtsConfig(
                model = OfflineTtsModelConfig(
                    vits = OfflineTtsVitsModelConfig(
                        model = File(base, ONNX_FILE).absolutePath,
                        tokens = File(base, TOKENS_FILE).absolutePath,
                        dataDir = dataDir.absolutePath
                    ),
                    numThreads = 2
                )
            )

            val t0 = System.currentTimeMillis()
            val instance = OfflineTts(null, config)
            val dt = System.currentTimeMillis() - t0
            tts = instance
            dbg("init: OfflineTts creado en ${dt}ms")

            try {
                val s0 = System.currentTimeMillis()
                val test = instance.generate("prueba", 0, 1.0f)
                val sdt = System.currentTimeMillis() - s0
                var peak = 0f
                for (s in test.samples) if (abs(s) > peak) peak = abs(s)
                dbg("smoke: samples=${test.samples.size} rate=${test.sampleRate} peak=$peak took=${sdt}ms")
            } catch (t: Throwable) {
                dbg("smoke THREW ${t.javaClass.simpleName}: ${t.message}")
            }

            onReady()
            dbg("init.worker END")
        } catch (t: Throwable) {
            dbg("init.worker THREW ${t.javaClass.simpleName}: ${t.message}")
            onError(t.message ?: "Error desconocido")

    private fun ensureModelOnDisk(): File {
        val outDir = File(context.filesDir, ASSET_DIR)
        val marker = File(outDir, ".ok")
        if (marker.exists()) {
            dbg("ensureModelOnDisk: ya copiado en ${outDir.path}")
            return outDir
        }
        dbg("ensureModelOnDisk: copiando ${ASSET_DIR} a ${outDir.path}")
        val t0 = System.currentTimeMillis()
        if (outDir.exists()) outDir.deleteRecursively()
        copyAsset(ASSET_DIR, outDir)
        marker.writeText("1")
        dbg("ensureModelOnDisk: copiado en ${System.currentTimeMillis() - t0}ms")
        return outDir
    }

    private fun copyAsset(path: String, dest: File) {
        val children = context.assets.list(path)
        if (children.isNullOrEmpty()) {
            dest.parentFile?.mkdirs()
            try {
                context.assets.open(path).use { input ->
                    dest.outputStream().use { output -> input.copyTo(output) }
                }
            } catch (_: java.io.FileNotFoundException) {
                dest.mkdirs()
            }
        } else {
            dest.mkdirs()
            children.forEach { child ->
                copyAsset("$path/$child", File(dest, child))
            }
        }
    }

    override fun speak(text: String, interruptible: Boolean) {
        if (shuttingDown) {
            notifyComplete()
            return
        }
        val engine = tts
        if (engine == null) {
            dbg("speak sin modelo")
            notifyComplete()
            return
        }

        currentJob?.cancel()
        currentJob = scope.launch {
            try {
                dbg("speak(\"$text\") generating...")
                val t0 = System.currentTimeMillis()
                val audio = engine.generate(text, 0, currentSpeed)
                val dt = System.currentTimeMillis() - t0

                var peak = 0f
                for (s in audio.samples) if (abs(s) > peak) peak = abs(s)
                dbg("generate: samples=${audio.samples.size} rate=${audio.sampleRate} peak=$peak took=${dt}ms")

                if (audio.samples.isNotEmpty() && peak > 0f) {
                    playAudio(audio.samples, audio.sampleRate)
                } else {
                    dbg("generate vacío/silencio (samples=${audio.samples.size}, peak=$peak)")
                }
            } catch (e: CancellationException) {
                dbg("speak cancelado")
                throw e
            } catch (t: Throwable) {
                dbg("speak THREW ${t.javaClass.simpleName}: ${t.message}")
            } finally {
                notifyComplete()
            }
        }
    }

    override fun stop() {
        dbg("stop()")
        currentJob?.cancel()
        currentJob = null
        try { currentTrack?.stop() } catch (_: Throwable) {}
        try { currentTrack?.release() } catch (_: Throwable) {}
        currentTrack = null
        paused = false
        notifyComplete()
    }

    override fun pause() {
        dbg("pause()")
        paused = true

    override fun resume() {

        paused = false
    }

    override fun isPaused(): Boolean = paused

    override fun setSpeed(rate: Float) {

    }

    override fun shutdown() {

        shuttingDown = true
        stop()
        try { tts?.release() } catch (_: Throwable) {}
        tts = null
        scope.cancel()
    }

    private suspend fun playAudio(samples: FloatArray, sampleRate: Int) {
        val pcmBytes = ByteArray(samples.size * 2)
        for (i in samples.indices) {
            val clamped = samples[i].coerceIn(-1f, 1f)
            val s = (clamped * 32767f).toInt()
            pcmBytes[2 * i] = (s and 0xFF).toByte()
            pcmBytes[2 * i + 1] = ((s shr 8) and 0xFF).toByte()
        }

        var track: AudioTrack? = null
        try {
            val minBuf = AudioTrack.getMinBufferSize(
                sampleRate, AudioFormat.CHANNEL_OUT_MONO, AudioFormat.ENCODING_PCM_16BIT
            )
            val bufSize = maxOf(minBuf, pcmBytes.size)

            track = AudioTrack.Builder()
                .setAudioAttributes(
                    AudioAttributes.Builder()
                        .setUsage(AudioAttributes.USAGE_MEDIA)
                        .setContentType(AudioAttributes.CONTENT_TYPE_MUSIC)
                        .build()
                )
                .setAudioFormat(
                    AudioFormat.Builder()
                        .setEncoding(AudioFormat.ENCODING_PCM_16BIT)
                        .setSampleRate(sampleRate)
                        .setChannelMask(AudioFormat.CHANNEL_OUT_MONO)
                        .build()
                )
                .setBufferSizeInBytes(bufSize)
                .setTransferMode(AudioTrack.MODE_STREAM)
                .build()

            dbg("playAudio: state=${track.state} pcm=${pcmBytes.size}B rate=$sampleRate bufSize=$bufSize")
            if (track.state != AudioTrack.STATE_INITIALIZED) {
                dbg("playAudio: AudioTrack NO inicializado")
                return
            }

            currentTrack = track
            track.play()

            // Escritura por chunks para permitir pausa en caliente
            var offset = 0
            while (offset < pcmBytes.size) {
                if (shuttingDown) break
                if (paused) {
                    try { track.pause() } catch (_: Throwable) {}
                    dbg("playAudio: pausado en offset=$offset/${pcmBytes.size}")
                    while (paused && !shuttingDown) delay(50)
                    if (shuttingDown) break
                    try { track.play() } catch (_: Throwable) {}
                    dbg("playAudio: reanudado en offset=$offset")
                }
                val toWrite = minOf(WRITE_CHUNK, pcmBytes.size - offset)
                val written = track.write(pcmBytes, offset, toWrite)
                if (written <= 0) {
                    dbg("playAudio: write=$written en offset=$offset, abortando")
                    break
                }
                offset += written
            }
            dbg("playAudio: escrito $offset/${pcmBytes.size}")

            val frames = pcmBytes.size / 2
            val expectedMs = frames * 1000L / sampleRate
            val deadline = System.currentTimeMillis() + expectedMs + 2000L
            var lastHead = 0
            while (System.currentTimeMillis() < deadline) {
                if (shuttingDown) break
                lastHead = track.playbackHeadPosition
                if (lastHead >= frames) break
                delay(40)
            }
            dbg("playAudio: head=$lastHead/$frames")
            delay(100)
        } catch (e: CancellationException) {
            throw e
        } catch (t: Throwable) {
            dbg("playAudio THREW ${t.javaClass.simpleName}: ${t.message}")
        } finally {
            try { track?.stop() } catch (_: Throwable) {}
            try { track?.release() } catch (_: Throwable) {}
            if (currentTrack === track) currentTrack = null
        }
    }

    private fun notifyComplete() {
        val cb = onComplete
        onComplete = null
        cb?.invoke()
    }
}

import android.content.Context
import io.github.stringmanolo.vocalia.util.InternalDebug
import java.util.concurrent.CountDownLatch
import java.util.concurrent.TimeUnit

class TtsManager(private val context: Context) {

    enum class EngineMode { ESPEAK, SHERPA }

    var onEngineReady: ((TtsEngine) -> Unit)? = null

    @Volatile private var currentMode: EngineMode = EngineMode.ESPEAK
    @Volatile private var currentEngine: TtsEngine? = null

    private var espeakEngine: EspeakNgEngine? = null
    private var sherpaEngine: SherpaOnnxEngine? = null
    @Volatile private var sherpaReady = false
    @Volatile private var sherpaLoading = false

    @Volatile private var speaking = false
    @Volatile private var paused = false
    @Volatile private var stopped = false
    @Volatile private var speakThread: Thread? = null
    @Volatile private var currentChunkText: String? = null

    private fun dbg(msg: String) { InternalDebug.mark("[${Thread.currentThread().name}] TtsManager: $msg") }

    fun init() {
        val espeak = EspeakNgEngine(context)
        espeakEngine = espeak
        espeak.init(
            onReady = {
                dbg("EspeakNg listo")
                currentEngine = espeak
                currentMode = EngineMode.ESPEAK
                onEngineReady?.invoke(espeak)
            },
            onError = { dbg("EspeakNg falló: $it") }
        )
    }

    fun setEngineAsync(mode: EngineMode, callback: (Boolean, String) -> Unit) {
        when (mode) {
            EngineMode.ESPEAK -> {
                val e = espeakEngine
                if (e != null) {
                    currentEngine = e
                    currentMode = EngineMode.ESPEAK
                    callback(true, "voz por defecto activada")
                } else callback(false, "espeak no disponible")
            }
            EngineMode.SHERPA -> {
                if (sherpaReady) {
                    currentEngine = sherpaEngine
                    currentMode = EngineMode.SHERPA
                    callback(true, "voz inteligente activada")
                    return
                }
                if (sherpaLoading) { callback(false, "voz inteligente cargándose"); return }
                sherpaLoading = true
                Thread({
                    try {
                        val sherpa = SherpaOnnxEngine(context)
                        sherpa.init(
                            onReady = {
                                sherpaEngine = sherpa
                                sherpaReady = true
                                sherpaLoading = false
                                currentEngine = sherpa
                                currentMode = EngineMode.SHERPA
                                callback(true, "voz inteligente activada")
                            },
                            onError = {
                                sherpaEngine = null
                                sherpaReady = false
                                sherpaLoading = false
                                callback(false, "voz inteligente no disponible")
                            }
                        )
                    } catch (t: Throwable) {
                        sherpaEngine = null
                        sherpaReady = false
                        sherpaLoading = false
                        callback(false, "voz inteligente no disponible")
                    }
                }, "sherpa-load").start()
            }
        }
    }

    fun speak(text: String, onStart: (() -> Unit)? = null, onComplete: (() -> Unit)? = null) {
        if (speaking) {
            dbg("speak: ya hablando, ignorando")
            onComplete?.invoke()
            return
        }
        val engine = currentEngine ?: run { onComplete?.invoke(); return }

        speaking = true
        paused = false
        stopped = false
        val chunks = splitIntoChunks(text)
        dbg("speak: ${chunks.size} chunks, ${text.length} chars")

        val th = Thread({
            var started = false
            try {
                for ((idx, chunk) in chunks.withIndex()) {
                    if (stopped) { dbg("speak: stop en chunk $idx"); break }
                    if (paused) {
                        engine.pause()
                        dbg("speak: pausado en chunk $idx")
                        while (paused && !stopped) Thread.sleep(100)
                        if (stopped) break
                        engine.resume()
                        dbg("speak: reanudado en chunk $idx")
                    }

                    currentChunkText = chunk
                    if (!started) { started = true; onStart?.invoke() }

                    val latch = CountDownLatch(1)
                    engine.onComplete = { latch.countDown() }
                    engine.speak(chunk)
                    latch.await(180, TimeUnit.SECONDS)
                }
            } catch (t: Throwable) {
                dbg("speak: THREW ${t.javaClass.simpleName}: ${t.message}")
            } finally {
                currentChunkText = null
                speaking = false
                paused = false
                stopped = false
                onComplete?.invoke()
            }
        }, "tts-chunk")
        speakThread = th
        th.start()
    }

    fun pause() {
        dbg("pause")
        paused = true
        currentEngine?.pause()
    }

    fun resume() {
        dbg("resume")
        paused = false
        currentEngine?.resume()
    }

    fun isSpeaking(): Boolean = speaking
    fun isPaused(): Boolean = paused
    fun getCurrentChunkText(): String? = currentChunkText

    fun stop() {
        dbg("stop")
        stopped = true
        paused = false
        currentEngine?.stop()
        try { speakThread?.join(2000) } catch (_: InterruptedException) {}
        currentChunkText = null
    }

    fun shutdown() {
        dbg("shutdown")
        stopped = true
        try { speakThread?.join(2000) } catch (_: InterruptedException) {}
        try { espeakEngine?.shutdown() } catch (_: Throwable) {}
        try { sherpaEngine?.shutdown() } catch (_: Throwable) {}
        currentEngine = null
        espeakEngine = null
        sherpaEngine = null
        sherpaReady = false
        sherpaLoading = false
    }

    private fun splitIntoChunks(text: String): List<String> {
        // 5000 chars: en la práctica el texto entero de un tirón (sin pausas intermedias)
        if (text.length <= 5000) return listOf(text)
        val sentences = text.split(Regex("(?<=[.,;:!?])\\s+")).filter { it.isNotBlank() }
        val chunks = mutableListOf<String>()
        var buf = StringBuilder()
        for (s in sentences) {
            if (buf.length + s.length > 5000 && buf.isNotEmpty()) {
                chunks.add(buf.toString().trim())
                buf = StringBuilder()
            }
            buf.append(s).append(' ')
        }
        if (buf.isNotEmpty()) chunks.add(buf.toString().trim())
        return chunks.ifEmpty { listOf(text) }
    }
}

object CrashHandler {

    fun install(context: Context) {
        val appContext = context.applicationContext
        val defaultHandler = Thread.getDefaultUncaughtExceptionHandler()

        Thread.setDefaultUncaughtExceptionHandler { thread, throwable ->
            try {
                val sw = StringWriter()
                throwable.printStackTrace(PrintWriter(sw))
                val timestamp = SimpleDateFormat(
                    "yyyy-MM-dd HH:mm:ss", Locale.getDefault()
                ).format(Date())
                val entry = "=== CRASH $timestamp (thread: ${thread.name}) ===\n${sw}\n\n"

                // Interno (siempre accesible por la app)
                try {
                    File(appContext.filesDir, "crash.log").appendText(entry)
                } catch (_: Throwable) {}

                // Externo (accesible desde Termux en Android 10)
                try {
                    val extDir = appContext.getExternalFilesDir("logs")
                    extDir?.mkdirs()
                    File(extDir, "crash.log").appendText(entry)
                } catch (_: Throwable) {}
            } catch (_: Throwable) {}
            defaultHandler?.uncaughtException(thread, throwable)
        }
    }
}

/**
 * Logger a disco que sobrevive a crashes nativos (SIGSEGV, SIGABRT).
 *
 * Escribe de forma SÍNCRONA (appendText cierra el FileOutputStream antes
 * de retornar, así que el contenido llega al page cache del kernel y
 * sobrevive a la muerte del proceso).
 *
 * Uso:
 *   InternalDebug.init(context)   // una vez, al arrancar la app
 *   InternalDebug.mark("label")   // N veces, en cualquier sitio
 */
object InternalDebug {

    private const val FILE_NAME = "INTERNAL_DEBUG_FILE"
    private val dateFormat = SimpleDateFormat("HH:mm:ss.SSS", Locale.US)

    @Volatile private var appContext: Context? = null

    fun init(context: Context) {
        if (appContext == null) {
            appContext = context.applicationContext
            mark("=== InternalDebug initialized (pid=${android.os.Process.myPid()}) ===")
        }
    }

    fun mark(label: String) {
        val ctx = appContext ?: return
        val line = "${dateFormat.format(Date())} [pid=${android.os.Process.myPid()}] $label\n"

        // 1) Almacenamiento interno: siempre accesible con run-as
        try {
            File(ctx.filesDir, FILE_NAME).appendText(line)
        } catch (_: Throwable) {}

        // 2) Almacenamiento externo de la app: accesible desde Termux en Android 10
        try {
            val ext = ctx.getExternalFilesDir(null)
            if (ext != null) {
                if (!ext.exists()) ext.mkdirs()
                File(ext, FILE_NAME).appendText(line)
            }
        } catch (_: Throwable) {}
    }

    /** Borra el archivo. Útil antes de cada test. */
    fun clear() {
        val ctx = appContext ?: return
        try { File(ctx.filesDir, FILE_NAME).delete() } catch (_: Throwable) {}
        try { ctx.getExternalFilesDir(null)?.let { File(it, FILE_NAME).delete() } } catch (_: Throwable) {}
    }
}

package io.github.stringmanolo.vocalia.util

import java.text.SimpleDateFormat
import java.util.*

object VocaliaLogger {
    private const val MAX_LINES = 500
    private val logs = Collections.synchronizedList(mutableListOf<String>())
    private val dateFormat = SimpleDateFormat("HH:mm:ss.SSS", Locale.getDefault())

    fun d(tag: String, message: String) {
        addLog("D", tag, message)
    }

    fun e(tag: String, message: String, tr: Throwable? = null) {
        addLog("E", tag, "$message ${tr?.stackTraceToString() ?: ""}")
    }

    fun i(tag: String, message: String) {
        addLog("I", tag, message)
    }

    fun w(tag: String, message: String) {
      addLog("W", tag, message)
    }

    fun v(tag: String, message: String) {
      addLog("V", tag, message)
    }

    private fun addLog(level: String, tag: String, message: String) {
        val timestamp = dateFormat.format(Date())
        val line = "$timestamp $level/$tag: $message"
        synchronized(logs) {
            logs.add(line)
            if (logs.size > MAX_LINES) {
                logs.removeAt(0)
            }
        }
    }

    fun getAllLogs(): String {
        synchronized(logs) {
            return logs.joinToString("\n")
        }
    }

    fun clear() {
        synchronized(logs) { logs.clear() }
    }
}

     * Las escribe en INTERNAL_DEBUG_FILE para que el usuario pueda leerlas
     * desde Termux sin necesitar adb.
     *
     * Se ejecuta en un hilo aparte para no bloquear el arranque.
     */
    private fun dumpPreviousLogcat() {

            try {
                val proc = Runtime.getRuntime().exec(arrayOf("logcat", "-d", "-t", "800"))
                val out = proc.inputStream.bufferedReader().readText()
                proc.waitFor()

                val filtered = out.lines()
                    .filter { line ->
                        line.contains("sherpa", ignoreCase = true) ||
                        line.contains("espeak", ignoreCase = true) ||
                        line.contains("vocalia", ignoreCase = true) ||
                        line.contains("SIGSEGV", ignoreCase = true) ||
                        line.contains("SIGABRT", ignoreCase = true) ||
                        line.contains("Fatal signal", ignoreCase = true) ||
                        line.contains("libonnxruntime", ignoreCase = true) ||
                        line.contains("dlopen", ignoreCase = true) ||
                        line.contains("UnsatisfiedLink", ignoreCase = true)
                    }
                    .joinToString("\n")

                if (filtered.isNotBlank()) {
                    InternalDebug.mark("[LOGCAT-ANTERIOR] inicio")
                    // Una sola línea con todo el bloque, para no fragmentar el archivo
                    InternalDebug.mark(filtered)
                    InternalDebug.mark("[LOGCAT-ANTERIOR] fin")
                } else {
                    InternalDebug.mark("[LOGCAT-ANTERIOR] sin líneas relevantes")
                }
            } catch (t: Throwable) {
                InternalDebug.mark("[LOGCAT-ANTERIOR] THREW ${t.javaClass.simpleName}: ${t.message}")
            }
        }, "logcat-dump").start()

    private val listener = object : RecognitionListener {
        override fun onPartialResult(hypothesis: String?) { onPartialResult?.invoke(hypothesis ?: "") }
        override fun onResult(hypothesis: String?) { onResult?.invoke(hypothesis ?: "") }
        override fun onFinalResult(hypothesis: String?) {}
        override fun onError(exception: Exception?) {
            Log.e(TAG, "Error reconocimiento", exception)
            onError?.invoke(exception?.message ?: "Error")
        }
        override fun onTimeout() {}
    }

    fun init(grammar: String, onReady: () -> Unit) {
        currentGrammar = grammar
        StorageService.unpack(
            context,
            "vosk-model-small-es-0.42",
            "model",
            { loadedModel ->
                model = loadedModel
                Log.i(TAG, "Modelo cargado, grammar de ${grammar.length} chars")
                onReady()
            },
            { exception ->
                Log.e(TAG, "Error cargando modelo", exception)
                onError?.invoke("Error cargando modelo: ${exception.message}")
            }
        )
    }

    fun startListening() {
        if (speechService != null) return
        val m = model ?: run {
            Log.w(TAG, "startListening sin modelo")
            return
        }
        try {
            val recognizer = Recognizer(m, 16000.0f, currentGrammar)
            speechService = SpeechService(recognizer, 16000.0f)
            speechService?.startListening(listener)
            Log.i(TAG, "startListening OK (grammar=${currentGrammar.length} chars)")
        } catch (e: IOException) {
            Log.e(TAG, "startListening falló", e)
            onError?.invoke("Error startListening: ${e.message}")
        }
    }

    fun stopListening() {
        speechService?.stop()
        speechService = null
    }

    /** Cambia la gramática activa. Si el servicio está escuchando, lo reinicia con la nueva. */
    fun setGrammar(grammar: String) {
        if (grammar == currentGrammar && speechService != null) return
        currentGrammar = grammar
        Log.i(TAG, "setGrammar (${grammar.length} chars), speechService=${speechService != null}")
        if (speechService != null) {
            stopListening()
            startListening()
        }
    }

    fun shutdown() {
        stopListening()
        model?.close()
        model = null
    }

    fun beep() {
        Thread {
            var tg: ToneGenerator? = null
            try {
                tg = ToneGenerator(AudioManager.STREAM_MUSIC, 60)
                tg.startTone(ToneGenerator.TONE_PROP_BEEP, 100)
                Thread.sleep(150)
            } catch (_: Throwable) {} finally {
                try { tg?.release() } catch (_: Throwable) {}
            }
        }.start()
    }
}

package io.github.stringmanolo.vocalia
import io.github.stringmanolo.vocalia.util.VocaliaLogger

import android.app.AlarmManager
import android.app.PendingIntent
import android.content.BroadcastReceiver
import android.content.Context
import android.content.Intent
import android.os.Build

class WatchdogReceiver : BroadcastReceiver() {

    companion object {
        const val TAG = "WatchdogReceiver"
        const val ACTION_BOOT_START = "io.github.stringmanolo.vocalia.action.BOOT_START"
        const val ACTION_WATCHDOG   = "io.github.stringmanolo.vocalia.action.WATCHDOG"
        private const val REQUEST_BOOT = 100
        private const val REQUEST_WATCHDOG = 101
        // setAndAllowWhileIdle respeta como mínimo ~60 s entre disparos.
        private const val WATCHDOG_INTERVAL_MS = 59_000L

        fun pendingIntent(context: Context, action: String, requestCode: Int): PendingIntent {
            val intent = Intent(context, WatchdogReceiver::class.java).apply {
                this.action = action
            }
            return PendingIntent.getBroadcast(
                context, requestCode, intent,
                PendingIntent.FLAG_UPDATE_CURRENT or PendingIntent.FLAG_IMMUTABLE
            )
        }

        fun scheduleWatchdog(context: Context) {
            val alarmManager = context.getSystemService(Context.ALARM_SERVICE) as AlarmManager
            val triggerAt = System.currentTimeMillis() + WATCHDOG_INTERVAL_MS
            val pi = pendingIntent(context, ACTION_WATCHDOG, REQUEST_WATCHDOG)
            alarmManager.setAndAllowWhileIdle(AlarmManager.RTC_WAKEUP, triggerAt, pi)
        }

        private fun startServiceSafely(context: Context) {
            try {
                val intent = Intent(context, VocaliaService::class.java)
                if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O) {
                    context.startForegroundService(intent)
                } else {
                    context.startService(intent)
                }
            } catch (e: Exception) {
                // Android 12+ puede lanzar ForegroundServiceStartNotAllowedException
                VocaliaLogger.w(TAG, "No se pudo arrancar el servicio: ${e.message}")
            }
        }
    }

    override fun onReceive(context: Context, intent: Intent) {
        when (intent.action) {
            ACTION_BOOT_START -> {
                VocaliaLogger.i(TAG, "Arranque post-boot")
                if (!VocaliaService.isRunning) startServiceSafely(context)
                scheduleWatchdog(context)
            }
            ACTION_WATCHDOG -> {
                VocaliaLogger.d(TAG, "Tick watchdog (running=${VocaliaService.isRunning})")
                if (!VocaliaService.isRunning) startServiceSafely(context)
                scheduleWatchdog(context)
            }
        }
    }
}
